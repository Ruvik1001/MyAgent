# Дежурный ЦУП

Ночная вахта районного центра УВД «Север». В эфире пусто, на пульте журнал,
дежурный не отвечает «из головы».

## Мотивирующий абзац (Project Statement)

Это не общий ассистент и не оболочка. Человек садится за пульт связи:
слева журнал смены, в центре эфир, справа табло частоты 124.7 и «тишина эфира».
Дежурный — ReAct-агент на OpenAI Agents SDK. Журналист ходит в File Search
по книге связи, метео берёт сводку с MCP `weathernow`, перед «вызвать ещё раз»
читается скилл регламента. Строка, которую смена решила записать, падает
в живую ленту, а не растворяется в чате.

Тема продолжает «Радиотишину» и пьесу «Ночная вахта»: Сокол-17 молчит с 21:14,
в журнале 2014 года «камня не вижу», позывной «Тихий» закрыт. Ответ без журнала
здесь считается браком.

## Что внутри

- `app/` — агенты и FastAPI
- `web/` — пульт
- `corpus/` — журнал, позывные, регламент для RAG
- `skills/radio_watch/` — скилл вахты
- `ideas/duty-officer.md` — Idea File: промпты и критерии
- `REPORT.md` — короткий отчёт

Дежурный говорит с человеком. Журналист и метео — отдельные агенты,
их зовут как инструменты (`as_tool`), handoff на пульте нет: в эфире один голос.

## Как запустить

Ключи курса в `.env` (файл в git не кладём):

```text
wget https://storage.yandexcloud.net/ycpub/keys/.env.m1
mv .env.m1 .env
```

```text
pip install -r requirements.txt
python -m app
```

Браузер: http://127.0.0.1:8000

На старте корпус уходит в vector store (чанки 800/100). Если индекс не встал,
дежурный ищет по тем же файлам локально и пишет об этом, а не выдумывает.

## Использование ИИ

Дежурный, журналист и метео — модели Yandex AI Studio через Responses API
(`deepseek-v4.1-flash`, запас `qwen3.6-35b-a3b`). Оркестрация — OpenAI Agents SDK:
агентский цикл, стрим, агенты-как-инструменты.

Журнал и регламент модель не помнит: File Search по `corpus/` и запасной поиск
по файлам. Погода — hosted MCP `weathernow`, если шлюз молчит — Open-Meteo
по тем же координатам, не «на глаз». Перед решением о вызове читается скилл
`skills/radio_watch/SKILL.md`. Промпты и критерии — в Idea File.

## Выводы

ReAct жив, только если факт нельзя сказать без инструмента. Иначе дежурный
честно «вспоминает» 2014 год и лаба превращается в чат.

Второй урок — про очередь голов. Handoff на пульте путает: человеку нужен
один голос. Журналист и метео удобнее как `as_tool`.

Скилл имеет смысл, когда его зовут в момент решения, а не кладут целиком
в system prompt. Регламент про минуту между вызовами срабатывает, только
если дежурный его перечитывает на вопросе «можно вызвать сейчас».

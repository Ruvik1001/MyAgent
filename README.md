# Лабораторная работа: Мой Агент

## Задание

Создайте своего агента или многоагентную систему для какой-то предметной области. Либо агента общего назначения.

Используйте:
* OpenAI Agents либо другие аналогичные библиотеки (LangGraph/deepagents, Microsoft Agent Framework и др.)
* Свой оригинальный пользовательский интерфейс или оболочку [ma](https://github.com/shwars/ma)
* Набор инструментов, делающих вашего агента уникальным: инструкций RAG, скиллов, MCP-серверов и т.д.

В качестве вдохновения и минимальной реализации:
* [Доклад про создание своего агента в AI Studio](https://vkvideo.ru/live-220010299_456239347?pl=-220010299_5) на школе [SMILES-2026](https://smiles.skoltech.ru/) (англ)
* Репозиторий к мастер-классу "[Многоагентные системы в Yandex AI Studio: пишем своего кодинг‑агента для анализа данных](https://github.com/yandex-ai-studio/building-data-agent/)" 

## Отчёт

Код работы размещайте в этом репозитории, замените `README.md` на описание проекта. Не забудьте указать ФИО всех участников проекта с их ролями.

Также нужно снять короткое (3 мин) видео с демонстрацией работы агента и несколько скриншотов интерфейса (файла положите в `images`); вставьте все это ссылками в `README.md`

## Оценивание

Работа оценивается по баллам в 10-балльной системе:

* Минимальная реализация - минимальный ReAct-агент, с которым можно вести диалог [2 балла]
* Оригинальная идея агента [2 балла]
* Оригинальный пользовательский интерфейс [3 балла] 
* Наличие доп.инструментов: RAG, MCP, Skills и др. [3 балла]

Важнейшими элементами оценки являются:

* **Мотивирующий абзац** (*Project Statement*) - кратко описывает, чем ваша работа оригинальна, отличается от простейшей реализации, почему преподавателю стоит на неё внимательно и с интересом посмотреть.
* **AI Use Statement** - описание того, как генеративный ИИ и агенты использовались при выполнении работы. Подробно опишите используемые приёмы (авто-подготовка документации, спецификации, критерии проверки качества и т.д.), используемые агенты, нейросети и промпты. Последние разумно сохранить в формате [Idea File](https://soshnikov.com/channel/?id=ca3557) в репозитории.
* **Выводы** - чему вы научились, какие уроки для себя извлекли.
